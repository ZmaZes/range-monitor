# Range Monitor
Keep track of your vocal range, or some other pitch range.

### Features
- Create/Edit multiple ranges
- Set an absolute min/max as well as a comfortable min/max with visualization
- Set note via piano
- Export/Import via text

### Usage
- Toggle glissando mode to allow sliding your mouse across the notes instead of using it to move the keyboard.
- Export: Copies data to the clipboard as text. Save it to a text file for safekeeping.
- Import: Opens a window to paste in previously exported text.
- Use the plus button to create a new range, or click on a range to edit it.
- Press the X button to delete the current range.
- Press the ✓ button to close the edit menu.
- Use the lower row to select a range marker (lowest, lowest comfortable, highest comfortable, highest).
  <br>The currently selected range will have a blue indicator.
- Use the upper row of buttons to edit the range marker you selected.
  - Edit: Enter a note number (not intuitive, click on a note to see its note name and number).
    If the number you picked is not on the keyboard (less than 24 or greater than 107), it will cause issues.
  - Pick from Piano: Click this button and then press a piano key to set the selected range marker to that note
  - Play: Play the note associated with the currently selected range marker
  - Rename: Rename the range (you can also click on the range name itself)
- Use the very bottom row with the 2 arrows to visually move the range up or down (useful if you have multiple ranges)
